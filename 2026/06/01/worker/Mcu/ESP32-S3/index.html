选购指南

首先看使用的模组是否和官方的一样，以 ESP32-3 为例 分为 pcb 板载天线模组（不带 U）另外一种是外接天线模组（带 U，预留 ipex 接口）  ，天线是蓝牙和 WiFi 共用的合二为一的，自带的和外接的只是改变信号的强弱 穿透 和距离 不改变原本的 WiFi 或者蓝牙的版本 因为芯片原生固定硬的 WiFiX  BLEX 的版本，好像说的这种板子是开源的 所以很多盗版 或者小厂家买二手芯片 二手器件组装出来一个开发板

1.芯片：

2.模组：在芯片的基础上做个封装，加点外壳天线这些就算是一个模组了，下面分别是ESP32-S3的两个模组（带板载天线和不带天线的）

N16R8：16M闪存 + 8M运行内存

N：常温通用版，-40℃-85℃

16：板子的存储空间（类比电脑硬盘 512Gb 1Tb 或者手机的存储空间 128Gb 256Gb……），永久化存储，断电数据还在

R8：相当于电脑的内存条 程序运行是临时存储的变量 数据 缓存…，关闭程序或者断电释放清空 零时性的

3.开发版：把模组集成带板子上就是一个最小系统版了，能够直接烧录运行代码，系统版又分给你焊好 排针的可以用于插入到 PCB 版或者面板版上和没有焊排针的，这种可以用于贴片
自己做产品的话肯定是买最小的芯片单元贴片到自己设计的板子上然后做封装

认识引脚

GPIO

GPIO 通用输入输出： 用于输出/接收 高低电平，既可以往外输出也可以用于接收信号作为监测输入
GND 开发板上的GND是供地的(即内部是连通的，用来接负极)

关于电

交流电

交流电：家庭 220v 供电，工业 380v 三相电供电，不分正负极，有零线火线，且火线是周期波形一高一低上下围绕着零线，常见电源上面写着 50Hz 即表示电流一秒钟变换 50 次，(火线-电器设备-零线-电器设备-火线-电器设备-零线…),电压从高的一侧经过用电的器件后流入到电压低的一侧循环交替

直流电

直流电：常见的电池，电瓶，能用来存储正负电荷的，区分正负极，正极的电压高于负极的电压，所以固定从正极流入到用电设备，从负极流出(电源正极-用电设备正极-用电设备负极-电源负极)
在开发版上这里的电源正极就是 3.3V/5V,负极就是GND，当然也可以用GPIO输出一个高电平

上图是通过GPIO输出高低电平进行控制的，如果不写代码，可以直接用 3.3V连接 LED 正极，GND 连接负极
注:交流电规范话应该先接 用电元器件负极与 GND 这样万一没用断电也可以减少先接正极元器件烧毁的情况，当然还是规范化先断电再操作
相同点：都是电压高的流向电压低的一侧
不同点：交流电不分正负极，交流电是来回交替，直流电是固定方向

基础配置

如何开启 tinyusb

1.在项目的 main 文件夹里新建一个 idf_component.yml 用于管理依赖 这个类似于 Java 的 Maven/gradle
2.内容如下
dependencies:

esp_tinyusb: "~2.0.0"

3.打开ESP-IDF 终端

4.输入命令 idf.py add-dependency esp_tinyusb~2.0.0

5.图形化编辑配置报错 exited with code：2
导致的原因：我先用命令行 idf.py menuconfig 去看了里面的配置，然后退出后去尝试用 esp-idf 插件的sdk配置编辑器，就导致报错了，也可能是我手动之前把 sdkconfig 文件删了导致的

设置 flash 大小

设置PSRAM 大小

  • Quad Mode PSRAM：4 条数据线同时工作（四线模式）
  • Octal Mode PSRAM：8 条数据线同时工作（八线模式）

你可以理解为：

  • Quad 模式：走 4 车道的路，一次能过 4 辆车

  • Octal 模式：走 8 车道的高速，一次能过 8 辆车

    车道越多，数据传输速度越快。

ESP32-S3-WROOM-1-N16R8 型号里的 R8，就代表板载 8MB Octal PSRAM
Quad Mode PSRAM：老款、常见，速度上限较低（约 40MB/s），很多旧款模组用这个
Octal Mode PSRAM：新款、更快，速度上限接近 80MB/s，你的 N16R8 模组用的就是这种

构建与烧录

烧录时选择 UART 模式进行烧录

进入烧录(下载模式)

插若我们的烧录的固件导致设备插入电脑时电脑死机，无法烧录新的程序时
1.按住开发版的BOOT 键不松手，然后用 USB 线连接电脑和开发版，连接后看到开发版上亮灯也就是供电后，点按一下RESET 键(我好像没按也行)，然后再把 BOOT键松开，这样开发版就会进入下载模式，也就是不会往外去输出执行程序，电脑就不会死机了
2.这个时候就正常的去烧录程序吧
